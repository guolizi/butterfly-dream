## 一、核心思路

```
不是"Caroline 压力大时会做什么（4 个选项）"
而是"Caroline 的行为向量空间"

每个人的 L5 人格模型定义 TA 专属的行为向量空间：
  - 空间维度 = 行为特征维度（心理学支撑 + 数据驱动补充）
  - 空间范围 = TA 历史上所有行为的向量分布
  - 空间密度 = 某些区域行为密集（高概率），某些区域稀疏（低概率）
```

### 为什么向量空间优于固定类别

| 对比 | 固定类别方案 | 向量空间方案 |
|:----|:-----------|:-----------|
| **预测空间定义** | 需手动定类别，难覆盖所有可能 | **自然涌现**，空间边界由数据定义 |
| **新行为处理** | 不在列表 → 惊讶度=1.0，每次都报警 | 在空间边界内 → 正常，超出 → 报警 |
| **粒度** | 粗（4-5 个选项） | **连续**，可无限细化 |
| **跨人比较** | 类别不同无法比较 | 向量空间同构，可比较不同人的空间形状 |
| **演化追踪** | 需手动更新类别 | 空间自然漂移，协方差矩阵自动反映变化 |

## 二、行为向量维度定义

采用**核心心理学维度 + PCA 补充维度**的混合架构：

```
核心维度（11 维，心理学支撑）：
  大五人格映射    5 维  ← 与 L5 人格模型共享语义
  能量与动机      4 维  ← 行为驱动力
  情绪效价        2 维  ← 与情感维度衔接

补充维度（3~5 维，数据驱动）：
  PCA 从行为语料提取  ← 覆盖长尾语义，确保空间完备性

总维度：14~16 维
```

### 2.1 核心维度详解

#### 大五人格映射（5 维）

| 维度 | 含义 | 低分端 | 高分端 | 对应 L5 人格模型 |
|:----|:----|:------|:------|:----------------|
| **开放性** | 对新事物的接受度 | 保守、传统、偏好熟悉 | 好奇、创新、偏好探索 | 核心价值观/决策倾向 |
| **责任心** | 自我控制与目标导向 | 随性、拖延、不注重细节 | 自律、有条理、追求成就 | 决策倾向/当前人生阶段 |
| **外向性** | 社交能量来源 | 内向、独处恢复能量 | 外向、社交获得能量 | 关系模式/情绪调节模式 |
| **宜人性** | 合作与利他倾向 | 竞争、怀疑、自我优先 | 合作、信任、利他 | 关系模式/核心价值观 |
| **神经质** | 情绪稳定性 | 情绪稳定、抗压 | 情绪敏感、易焦虑 | 情绪调节模式 |

#### 能量与动机（4 维）

| 维度 | 含义 | 低分端 | 高分端 |
|:----|:----|:------|:------|
| **消耗性/恢复性** | 行为对能量的消耗程度 | 恢复能量（休息、放松） | 消耗能量（运动、工作） |
| **主动性/被动性** | 行为的发起方式 | 被动响应（等待、接受） | 主动发起（计划、行动） |
| **风险偏好** | 对不确定性的态度 | 规避风险（安全、稳妥） | 追求风险（冒险、尝试） |
| **延迟满足度** | 对即时 vs 长期回报的偏好 | 即时满足（享乐、冲动） | 延迟满足（规划、投资） |

#### 情绪效价（2 维）

| 维度 | 含义 | 低分端 | 高分端 |
|:----|:----|:------|:------|
| **愉悦度（Valence）** | 情感的正负方向 | 不愉快、负面 | 愉快、正面 |
| **唤醒度（Arousal）** | 情感的激活程度 | 平静、放松 | 激动、紧张 |

> 注：此处只取 VAD 中的 VA 两维，Dominance（支配度）保留在情感维度独立设计中。行为预测关注"会做什么"，VA 两维已足够描述行为的情感驱动。

### 2.2 PCA 补充维度

当核心 11 维无法充分表达某些长尾行为时（如"研究天体摄影"），从大规模行为语料中通过 PCA 提取 3~5 个潜在行为因子作为补充：

```
为什么用 PCA 而非 LLM 动态生成：
  - 确定性：PCA 是确定性的数学变换，每次结果一致
  - 正交性：PCA 天然产出正交维度，避免冗余
  - 数据驱动：从真实行为数据中涌现，而非 LLM 主观判断
  - 跨人可比：潜在因子对所有用户含义一致
  - 低成本：一次计算，无需持续 LLM 调用
```

## 三、向量映射方案

三阶段渐进实现：

| 阶段 | 做法 | 触发条件 | 一致性 | 成本 |
|:----|:----|:--------|:------|:----|
| **冷启动** | LLM 直接输出向量 + embedding 相似度缓存复用 | 0~200 条 | 中 | 高 |
| **成长期** | 训练 embedding→行为向量的回归模型（MLP），LLM 仅做 fallback | ≥ 200 条 | 高 | 低 |
| **持续校准** | 定期用新数据重训练映射模型 | 每周 | 高 | 极低 |

### 冷启动缓存机制

```
行为描述 → embedding 向量 → 检索最相似缓存
    ↓ 相似度 > 0.92          ↓ 相似度 ≤ 0.92
复用缓存向量                LLM 输出向量 → 写入缓存
```

## 四、条件概率预测

### 贝叶斯收缩 + 可学习上下文嵌入

```
人格先验 N(μ₀, Σ₀)  ← 长期稳定的行为分布
    ↓ 上下文编码 + 偏移
条件后验 N(μ_cond, Σ_cond)  ← 预测分布
    ↓
上下文强度 λ ∈ [0,1] 控制预测分散度
```

| 数据量 | 做法 | 说明 |
|:-----|:----|:----|
| 同一上下文 < 30 条 | 整体平移 | 人格先验 + 上下文偏移向量，向先验收缩 |
| 同一上下文 ≥ 30 条 | 条件高斯近似 | 贝叶斯推断，数据驱动条件分布 |
| 上下文模糊（λ≈0） | 接近人格先验 | 预测分散，置信度低 |
| 上下文强烈（λ≈1） | 接近条件分布 | 预测聚焦，置信度高 |

## 五、空间成熟度判断

| 级别 | 行为记录数 | 能力 |
|:----|:---------:|:----|
| **MVP** | ≥ 30 条 | 协方差可逆，能区分极端异常（马氏距离） |
| **基础可用** | ≥ 100 条 | 均值/协方差稳定，可做有意义概率预测 |
| **完全成熟** | ≥ 500 条 | 对细微上下文敏感，可检测人格漂移 |

### 冷启动 fallback

```
≥ 30 条  → 用户个人统计 + Ledoit-Wolf 收缩估计器（防奇异协方差）
10~29 条 → 用户数据 + 人群基线加权混合（α = n/30）
< 10 条  → 基于 L5 Phase 1 人格评估匹配预置人格模板分布
0 条     → 全局默认分布
```

## 六、空间漂移检测

### 双窗口 CUSUM 检验

- 短期窗口（最近 30 条）vs 长期窗口（最近 200 条）
- 计算均值向量的马氏距离
- 连续 3 个窗口超过 χ² 阈值 → 触发人格漂移告警

### EWMA 趋势监控

- 对每个维度均值施加指数加权移动平均
- 多个维度趋势一致朝向同一语义方向 → 标记为人格变化

### 漂移响应

- 不立即丢弃历史数据
- 提高近期数据权重（增大时间衰减因子 α）
- 明确识别为人格变化后，存档旧模型，从近期窗口重建

## 七、与矛盾检测的关系

```
新行为 → 向量映射 → 马氏距离 → 惊讶度
    ↓
惊讶度 × 分布置信度 → 矛盾信号强度
    ↓
距离小 = 在人格空间内 = 正常行为
距离大 = 超出人格空间 = 高惊讶度 → 触发矛盾检测
```

## 八、整体实现路径

| Phase | 内容 | 数据要求 |
|:----|:----|:--------|
| **Phase 1（MVP）** | 固定 11 维核心维度 + LLM 直接输出向量 + 简单多元高斯 + 整体平移 | ≥ 30 条 |
| **Phase 2（增强）** | PCA 补充维度 + embedding 映射模型训练 + 贝叶斯收缩条件概率 | ≥ 200 条 |
| **Phase 3（演进）** | 漂移检测 + 群体先验库 + 主动学习 + 校准 | ≥ 500 条 |
