## 一、核心思路

```
不是"Caroline 压力大时会做什么（4 个选项）"
而是"Caroline 的行为向量空间"

每个人的 L5 人格模型定义 TA 专属的行为向量空间：
  - 空间维度 = 行为特征维度（心理学支撑 + 数据驱动补充）
  - 空间范围 = TA 历史上所有行为的向量分布
  - 空间密度 = 某些区域行为密集（高概率），某些区域稀疏（低概率）
```

### 为什么向量空间优于固定类别

| 对比 | 固定类别方案 | 向量空间方案 |
|:----|:-----------|:-----------|
| **预测空间定义** | 需手动定类别，难覆盖所有可能 | **自然涌现**，空间边界由数据定义 |
| **新行为处理** | 不在列表 → 惊讶度=1.0，每次都报警 | 在空间边界内 → 正常，超出 → 报警 |
| **粒度** | 粗（4-5 个选项） | **连续**，可无限细化 |
| **跨人比较** | 类别不同无法比较 | 向量空间同构，可比较不同人的空间形状 |
| **演化追踪** | 需手动更新类别 | 空间自然漂移，协方差矩阵自动反映变化 |

## 二、行为向量维度定义

采用**核心心理学维度 + GMM 行为模式维度**的混合架构：

```
核心维度（11 维，心理学支撑）：
  大五人格映射    5 维  ← 与 L5 人格模型共享语义
  能量与动机      4 维  ← 行为驱动力
  情绪效价        2 维  ← 与情感维度衔接

补充维度（3~5 维，数据驱动）：
  GMM 行为模式聚类  ← 覆盖长尾语义，每个模式可命名

总维度：14~16 维
```

### 2.1 核心维度详解

#### 大五人格映射（5 维）

| 维度 | 含义 | 低分端 | 高分端 | 对应 L5 人格模型 |
|:----|:----|:------|:------|:----------------|
| **开放性** | 对新事物的接受度 | 保守、传统、偏好熟悉 | 好奇、创新、偏好探索 | 核心价值观/决策倾向 |
| **责任心** | 自我控制与目标导向 | 随性、拖延、不注重细节 | 自律、有条理、追求成就 | 决策倾向/当前人生阶段 |
| **外向性** | 社交能量来源 | 内向、独处恢复能量 | 外向、社交获得能量 | 关系模式/情绪调节模式 |
| **宜人性** | 合作与利他倾向 | 竞争、怀疑、自我优先 | 合作、信任、利他 | 关系模式/核心价值观 |
| **神经质** | 情绪稳定性 | 情绪稳定、抗压 | 情绪敏感、易焦虑 | 情绪调节模式 |

#### 能量与动机（4 维）

| 维度 | 含义 | 低分端 | 高分端 |
|:----|:----|:------|:------|
| **消耗性/恢复性** | 行为对能量的消耗程度 | 恢复能量（休息、放松） | 消耗能量（运动、工作） |
| **主动性/被动性** | 行为的发起方式 | 被动响应（等待、接受） | 主动发起（计划、行动） |
| **风险偏好** | 对不确定性的态度 | 规避风险（安全、稳妥） | 追求风险（冒险、尝试） |
| **延迟满足度** | 对即时 vs 长期回报的偏好 | 即时满足（享乐、冲动） | 延迟满足（规划、投资） |

#### 情绪效价（2 维）

| 维度 | 含义 | 低分端 | 高分端 |
|:----|:----|:------|:------|
| **愉悦度（Valence）** | 情感的正负方向 | 不愉快、负面 | 愉快、正面 |
| **唤醒度（Arousal）** | 情感的激活程度 | 平静、放松 | 激动、紧张 |

> 注：此处只取 VAD 中的 VA 两维，Dominance（支配度）保留在情感维度独立设计中。行为预测关注"会做什么"，VA 两维已足够描述行为的情感驱动。

### 2.2 GMM 行为模式维度（替代 PCA）

当核心 11 维无法充分表达某些长尾行为时（如"研究天体摄影"），采用 **GMM（高斯混合模型）** 从用户历史行为中提取 3~5 个行为模式作为补充维度：

```
为什么用 GMM 而非 PCA：
  - 语义可解释：每个模式可命名（"深夜码农模式"），LLM Teacher 可理解
  - 软分配：P(mode_i | behavior) 后验概率，自然表达模糊性
  - 与现有框架同构：GMM = 多个多元高斯的混合，与 𝒩(μ, Σ) 同框架
  - LLM 标注一致性高：回答"这个行为像模式 A 的概率多大"比 PCA 打分直观
  - 长尾检测：距离所有模式都远 → 自然标记为"新颖行为"

补充维度 = P(mode_i | behavior) 后验概率，共 3~5 维
```

> PCA 的问题：PC1 是"0.3×开放性 + 0.5×外向性 - 0.2×消耗性 + ..."的混合轴，LLM 无法理解其语义，导致 Teacher 标注不一致 → Student 学到噪声。GMM 的每个分量是一个可命名的行为模式，LLM 可以直观回答"这个行为属于哪种模式"。

## 三、向量映射方案

采用**知识蒸馏（Teacher-Student）架构**，Teacher 使用**心理锚点投影**替代直接输出浮点数：

```
┌─────────────────────────────────────────────────┐
│              离线标注阶段（Teacher）               │
│                                                   │
│  历史行为库 → LLM + 心理锚点分类                  │
│  [系统提示：请选择该行为最匹配的心理锚点]          │
│    ↓                                              │
│  锚点相似度 → 加权合成 → 11 维向量               │
│    ↓                                              │
│  embedding 相似度缓存（复用相同行为的标注结果）     │
└─────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────┐
│              模型训练阶段（Student）               │
│                                                   │
│  伪标签 → 训练多任务回归网络 / 微调小 Transformer  │
│  11 维作为 11 个相关任务，共享底层特征提取层        │
│    ↓                                              │
│  轻量级 Student 模型（在线推理 < 1ms）             │
└─────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────┐
│              在线推理阶段                          │
│                                                   │
│  新行为 → 查 embedding 缓存                       │
│    ↓ 命中          ↓ 未命中                       │
│  复用缓存向量      Student 模型推理                │
│                      ↓ Student 置信度低            │
│                    锚点投影 LLM 推理（兜底）        │
│                      ↓                            │
│                    写入缓存                        │
└─────────────────────────────────────────────────┘
```

### Teacher：心理锚点投影

**核心问题**：LLM 不擅长输出精确浮点数（回归任务），但擅长分类。锚点投影将"输出 11 个浮点数"转化为"选择最匹配的心理锚点"（分类任务），再通过预计算的锚点坐标加权合成 11 维向量。

#### 锚点库设计

预定义 50 个心理锚点文本，覆盖 11 维空间的各个区域：

```
锚点示例（部分）：
  A01: "极度缺乏安全感"     → [O=-0.1, C=+0.2, E=-0.6, A=+0.5, N=+0.8, ...]
  A02: "充满探索欲"         → [O=+0.9, C=+0.3, E=+0.5, A=+0.2, N=-0.1, ...]
  A03: "深度专注状态"       → [O=-0.2, C=+0.9, E=-0.5, A=+0.1, N=-0.3, ...]
  A04: "社交能量满格"       → [O=+0.4, C=+0.1, E=+0.9, A=+0.6, N=-0.4, ...]
  A05: "疲惫无力感"         → [O=-0.3, C=-0.5, E=-0.7, A=+0.2, N=+0.6, ...]
  ...
  A50: "想要改变现状"       → [O=+0.6, C=+0.4, E=+0.2, A=+0.1, N=+0.3, ...]
```

每个锚点的 11 维坐标由**心理学专家标注**或**群体先验数据**预计算，确保锚点空间分布均匀。

#### 标注流程

```
输入: 行为描述（如"参加即兴戏剧工作坊"）

Step 1: LLM 分类（核心步骤）
  Prompt: "请从以下 50 个心理锚点中，选出最匹配该行为的 3~5 个锚点，
           并给出匹配度（0~1.0）。行为越符合锚点的心理状态，匹配度越高。"
  输出: {A02: 0.9, A04: 0.7, A19: 0.5, A33: 0.3}

Step 2: 加权合成 11 维向量
  v = Σ(w_i × anchor_i) / Σ(w_i)
  其中 w_i 是 LLM 输出的匹配度，anchor_i 是锚点的预计算 11 维坐标

Step 3: 缓存
  行为 embedding → (锚点选择结果, 合成向量) 写入缓存
  相同行为再次出现时直接复用
```

**为什么锚点投影优于直接输出浮点数：**

| 对比 | LLM 直接输出 11 维 | 锚点投影 |
|:----|:-----------------|:--------|
| **LLM 任务类型** | 回归（输出浮点数）❌ LLM 不擅长 | 分类（选锚点）✅ LLM 擅长 |
| **一致性** | 同行为不同次调用可能不同 ❌ | 同行为选相同锚点，投影确定 ✅ |
| **可调试** | 难以验证 11 个浮点数是否正确 ❌ | 可检查"这条事实匹配锚点 X"是否合理 ✅ |
| **校准** | LLM 倾向中间值，分布坍缩 ❌ | 锚点坐标预定义，分布可控 ✅ |
| **Student 训练** | 伪标签有噪声 ❌ | 伪标签更稳定 ✅ |

### Student：多任务回归网络

用 LLM 生成的伪标签（Pseudo-labels）训练轻量级模型：

```
多任务回归网络结构：
  Input: 行为描述 embedding（768 维）
    ↓
  共享层：2 层 Transformer / 2 层 MLP
    ↓
  11 个独立回归头（每个维度一个）
    ↓
  输出：11 维向量

  损失函数：每个维度独立 MSE + 维度间相关性正则化
```

### 三阶段渐进实现

| 阶段 | 做法 | 触发条件 | 一致性 | 成本 |
|:----|:----|:--------|:------|:----|
| **冷启动** | Teacher 锚点投影标注历史库 + embedding 缓存复用 | 0~200 条 | 高 | 高 |
| **成长期** | 训练 Student 多任务回归网络，锚点投影仅做兜底 | ≥ 200 条 | 高 | 低 |
| **持续校准** | Student 增量更新 + Teacher 周期性锚点重标注 | 每周 | 高 | 极低 |

### 冷启动缓存机制

```
行为描述 → embedding 向量 → 检索最相似缓存
    ↓ 相似度 > 0.92          ↓ 相似度 ≤ 0.92
复用缓存向量                锚点投影 LLM 推理 → 写入缓存
```

> 对于极其罕见的小众行为（Student 模型没见过），触发锚点投影 LLM 推理，保证语义不丢失——小众行为可能比大众行为更具人格判别力。

## 四、条件概率预测

### 协方差矩阵的三层保护

协方差矩阵面临两个核心问题：
1. **维度灾难**：14~16 维的全协方差矩阵需要 105~136 条独立行为才能可靠估计
2. **数值稳定性**：数据不足时协方差矩阵奇异（不可逆），马氏距离计算失败

采用**三层保护**确保始终可逆且信息最大化：

```
第一层：群体先验（保证可逆）
  Σ_base = Σ_population  ← 来自大五人格相似群体的协方差
  永远可逆（大样本估计）

第二层：Ledoit-Wolf 收缩（自动平衡群体 vs 个人）
  Σ_personal = λ·Σ_base + (1-λ)·Σ_sample

  λ 由 Ledoit-Wolf 解析解自动计算：
    - N 很小 → λ 接近 1（靠近群体先验）
    - N 很大 → λ 接近 0（靠近个人数据）
  → 无需手动设计 α 衰减策略

第三层：谱正则化兜底（防止极端情况）
  对 Σ_personal 做特征值分解
  max(eigenvalue, ε)  ← ε = 1e-6
  确保即使 Ledoit-Wolf 后仍有极小特征值，矩阵仍然可逆
```

> 注：Σ_sample 计算时使用无偏估计（除以 N-1 而非 N）。

### 条件高斯分布 + 三层递进上下文偏移

上下文（如"今天工作好累"、"刚和伴侣吵架"）不只是简单的过滤器，而是**改变空间形状的物理场**。

假设用户的基础人格空间为 𝒩(μ₀, Σ₀)，上下文向量为 C（由 LLM 或文本模型编码）：

#### 均值平移（倾向性偏移）

在 Phase 1（K=1 单高斯）阶段，全局线性矩阵 W·C 存在根本性问题：
- 同一个上下文对不同人的影响不同（"压力大"→A 去喝酒，B 去睡觉）
- 全局 W 互相抵消趋于 0，Per-user W 在数据极少时严重过拟合

采用**三层递进策略**解决：

```
第一层：LLM Zero-shot 偏移（主力）
  用户人格画像 + 上下文 → LLM Teacher → 偏移向量 Δμ
  缓存常见上下文的 Δμ，避免重复 LLM 调用
  → 零训练数据，完美解决个体差异

第二层：群体人格路由（降级）
  用户 → 大五人格 → 匹配 M 个人格原型
  W_user = Σ α_m · W_persona_m
  → 无需 LLM 调用，参数极少

第三层："承认无知"（安全兜底）
  强烈上下文 + K=1 → 削弱均值偏移 + 放大方差
  "我不确定你会做什么，所以我不乱猜"
  → 防止 MVP 阶段翻车
```

**第一层：LLM Zero-shot 偏移**

```
缓存表：
  context_hash → Δμ_vector

流程：
  新上下文 C → 计算 embedding → 查缓存
    ↓ 命中               ↓ 未命中
  复用 Δμ               LLM Teacher 生成 Δμ

LLM Prompt：
  "基于该用户的性格画像，当遇到 [上下文] 时，
  他在以下 11 个行为维度上，相比日常状态会增加还是减少？
  请输出一个 11 维的偏移向量（范围 -1 到 +1）。"

  最终：μ_cond = μ₀ + Δμ
```

**第二层：群体人格路由（缓存未命中且 LLM 不可用时的降级）**

```
M = 5 个人格原型（从大五聚类得到）：
  原型 1：外向抗压型（高外向性、低神经质）
  原型 2：内向敏感型（低外向性、高神经质）
  原型 3：理智工作狂（高责任心、低开放性）
  原型 4：社交达人（高外向性、高宜人性）
  原型 5：随性探索者（高开放性、低责任心）

新用户 → 计算与每个原型的相似度 α_m
W_user = Σ α_m · W_persona_m
μ_cond = μ₀ + W_user · C
```

**第三层："承认无知"（极端上下文的安全兜底）**

```
当满足以下条件时触发：
  1. K=1 阶段（单高斯）
  2. 上下文强度 > 阈值（如 f(C) 的 max 维度 > 1.5）
  3. 该上下文在缓存中命中次数 < 3（经验不足）

做法：
  μ_cond ≈ μ₀（均值几乎不变）
  Σ_cond = Σ_personal ⊙ diag(f(C))，其中 f(C) >> 1

效果：
  预测分布宽而平 → "可能做任何事"
  矛盾检测阈值自动放宽 → 不会误报异常
```

#### 协方差形变（不确定性增益）

```
Σ_cond = Σ_personal ⊙ diag(f(C))
```

f(C) 定义为**不确定性增益**，反映上下文对行为确定性的影响：

| f(C) 值 | 含义 | 示例上下文 | 效果 |
|:-------|:----|:----------|:----|
| **= 1.0** | 中性，方差不变 | "平平无奇的一天" | 接近人格先验 |
| **> 1.0** | 方差放大，行为更不可预测 | "情绪崩溃"、"重大变故" | 不确定性增加，置信度降低 |
| **< 1.0** | 方差缩小，行为更刻板 | "专注工作"、"习惯性行为" | 不确定性减少，置信度提高 |

```
贝叶斯视角：
  后验方差 = 先验方差 × 不确定性增益

  f(C) 与 λ（数据量分级）正交：
    λ 控制"群体 vs 个人"的权重（长期）
    f(C) 控制"上下文不确定性增益"（短期）
    两者独立，相乘即可
```

#### 采样与预测

```
预测不再是"找最近的点"，而是在偏移后的新空间 𝒩(μ_cond, Σ_cond) 中
进行蒙特卡洛采样 → 生成最可能的行为向量 → 映射回自然语言描述
```

### 与数据量分级的融合

| 数据量 | 均值处理 | 协方差处理 | 说明 |
|:-----|:--------|:----------|:----|
| 同一上下文 < 30 条 | μ_cond = μ₀ + α·Δμ_LLM（α = n/30） | Σ_cond = Σ_personal（保持，不形变） | LLM Zero-shot 偏移，α 向先验收缩 |
| 同一上下文 ≥ 30 条 | μ_cond = μ₀ + Δμ_LLM | Σ_cond = Σ_personal ⊙ diag(f(C)) | 全量偏移+形变 |

> 其中 Δμ_LLM 来自三层递进策略：第一层 LLM Zero-shot（缓存命中）→ 第二层群体人格路由（降级）→ 第三层"承认无知"（极端上下文兜底）。

### GMM 增强：从单高斯到多模式预测

上述方案假设行为是单峰的（一个高斯分布），但现实中用户在相同上下文下可能有多种截然不同的行为模式。引入 **GMM（高斯混合模型）** 将预测从"上下文偏移单高斯"升级为"上下文选择多模式"：

```
原始预测（单高斯）：
  p(x) = 𝒩(x | μ_cond, Σ_cond)

GMM 增强预测：
  p(x) = Σ P(z=k|x_context) · 𝒩(x | μ_k, Σ_k)
         ↑ 模式概率          ↑ 模式内行为分布
```

> **上下文的作用在 Phase 2+ 发生了质变：**
> - Phase 1（K=1）：上下文通过三层策略偏移均值（μ₀ + Δμ_LLM）
> - Phase 2+（K≥1）：上下文通过 P(z=k|x_context) **选择模式**，每个 μ_k 已经是个性化的行为模式
> - 三层策略中的 LLM Zero-shot 偏移和群体人格路由在 Phase 2+ 不再需要——GMM 的模式选择天然解决了个体差异

#### 核心思想

GMM 的每个分量代表一个**心理态（行为模式）**，用户在不同心理态之间跃迁：

```
模式 A："创作态" — 高开放性、低社交性、低消耗性
模式 B："社交态" — 高外向性、高愉悦度、高消耗性
模式 C："恢复态" — 低主动性、低消耗性、低唤醒度

上下文决定你处于哪个模式：
  "工作好累" → 60% 创作态, 10% 社交态, 30% 恢复态
  "周末聚会" → 10% 创作态, 80% 社交态, 10% 恢复态
```

#### 与当前方案的关系

当前方案是 GMM 的特例（K=1）：

```
当前方案（Phase 1）：
  p(x) = 𝒩(x | μ₀ + Δμ_LLM, Σ_personal ⊙ diag(f(C)))

等价于 GMM 的 K=1 情况：
  p(x) = P(z=1|x_context) · 𝒩(x | μ₁, Σ₁)
       = 1 · 𝒩(x | μ₀ + Δμ_LLM, Σ_personal ⊙ diag(f(C)))
```

GMM 增强后，当前方案的组件自然融入每个模式：

```
每个模式 k 有自己的：
  μ_k = 从用户历史行为学习的模式均值（已个性化，无需上下文偏移）
  Σ_k = Σ_personal_k ⊙ diag(f_k(C))  ← 模式内的不确定性增益

P(z=k|x_context) = 上下文决定模式概率
  → 可由 LLM 计算（"当前上下文下，用户处于哪种模式？"）
  → 也可由学习的分类器计算
```

> 注意：在 GMM 框架下，上下文的主要作用是**选择模式**而非偏移均值。每个模式 μ_k 已经是从用户历史行为中学习的个性化行为模式，不再需要 W·C 偏移。上下文仅在 Phase 1（K=1 单高斯）时通过三层策略偏移均值。

#### 具体例子

```
用户 Caroline 的 GMM（K=3）：

模式 A："创作态"
  μ_A = [开放性=+0.8, 社交性=-0.5, 消耗性=-0.3, ...]
  Σ_A = 中等方差（创作时行为相对稳定）

模式 B："社交态"
  μ_B = [开放性=+0.2, 社交性=+0.9, 消耗性=+0.4, ...]
  Σ_B = 小方差（社交行为模式固定）

模式 C："恢复态"
  μ_C = [开放性=-0.3, 社交性=-0.7, 消耗性=-0.8, ...]
  Σ_C = 大方差（恢复方式多样：睡觉/看剧/发呆）

上下文："Caroline 今天工作好累"
  → P(z=A|x_context) = 0.6（累了想创作）
  → P(z=B|x_context) = 0.1（不想社交）
  → P(z=C|x_context) = 0.3（可能直接休息）

预测分布：
  p(x) = 0.6·𝒩(x|μ_A, Σ_A) + 0.1·𝒩(x|μ_B, Σ_B) + 0.3·𝒩(x|μ_C, Σ_C)
  → 蒙特卡洛采样 → 最可能行为向量 → "画画"（模式 A 的典型行为）
```

#### GMM 与心理态跃迁

GMM 的引入意味着不再把用户看作一个静态的点，而是看作一个在不同心理态之间跃迁的动态系统：

```
用户状态 = 一个随时间演化的心理态分布

时间轴：
  工作态 ──→ 放松态 ──→ 社交态 ──→ 压力态 ──→ 创作态 ──→ ...
  
每个态有自己的：
  - 行为模式（均值 μ_k）
  - 灵活性（方差 Σ_k）
  - 典型上下文触发条件
```

#### 实施路径

| Phase | 模型 | 说明 |
|:----|:----|:----|
| **Phase 1（MVP）** | K=1，退化到单高斯 | 先跑通整个链路 |
| **Phase 2（增强）** | K=3~5，GMM 上线 | 从历史行为学习 GMM 分量，上下文决定模式概率 |
| **Phase 3（成熟）** | K 自适应 | 根据数据自动决定 K（BIC/AIC），模式随演化增减 |

### 完整流程

```
人格先验 𝒩(μ₀, Σ₀)
    ↓
Ledoit-Wolf 收缩：
  Σ_personal = λ·Σ_population + (1-λ)·Σ_sample
  λ 自动计算，谱正则化兜底
    ↓
Phase 1（K=1）：单高斯预测
  上下文 C → 三层递进策略 → Δμ_LLM
    ↓
  μ_cond = μ₀ + Δμ_LLM
  Σ_cond = Σ_personal ⊙ diag(f(C))
    ↓
  蒙特卡洛采样 → 行为向量 → 映射回自然语言
  ↓
Phase 2+（K≥1）：GMM 增强
  上下文 C → 模式概率 P(z=k|x_context)
    ↓
  每个模式 k：
    μ_k = 模式均值（已个性化，无需上下文偏移）
    Σ_k = Σ_personal_k ⊙ diag(f_k(C))
    ↓
  混合预测：
    p(x) = Σ P(z=k|x_context) · 𝒩(x | μ_k, Σ_k)
    ↓
  蒙特卡洛采样 → 行为向量 → 映射回自然语言
```

## 五、空间成熟度判断

### 收敛判断

采用**动态 GMM 监测为主 + 固定阈值兜底**的双重判断：

```
每新增 10 条行为数据，重新拟合 GMM：

1. GMM 分量均值向量变化余弦相似度 > 0.95（每个分量独立检查）
2. GMM 分量权重变化率 < 5%（分量分配趋于稳定）
3. 新增数据在 GMM 下的平均对数似然趋于平稳（变化率 < 5%）

同时满足 → 判定空间"已成熟/收敛"
否则 → 继续监测
```

> 与 PCA 监测的区别：GMM 监测的是**行为模式（分量）的稳定性**而非主成分方向。当 GMM 的分量均值、权重和似然都趋于稳定时，说明用户的行为模式已经固化，空间成熟。

固定阈值作为兜底参考：

| 级别 | 条件 | 实际使用的 Σ | 能力 |
|:----|:----|:------------|:----|
| **MVP** | N ≥ 1 | Σ = Σ_population（Ledoit-Wolf λ≈1） | 基于群体先验的异常检测 |
| **基础可用** | N ≥ 30 | λ 开始下降，个人数据开始影响 | 初步个性化预测 |
| **成熟** | GMM 收敛判定通过 | λ 接近 0，Σ ≈ Σ_sample | 完全个性化，对细微上下文敏感 |

> MVP 阶段不再要求 N > D，因为实际使用的是群体先验（永远可逆）。个人数据仅通过 Ledoit-Wolf 收缩逐步影响协方差矩阵。

> D(D+1)/2 是协方差矩阵自由参数数量，11 维至少需要 66 条独立行为才能可靠估计。

### 冷启动群体先验

在数据不足（空间未成熟）时，直接使用个人数据会导致协方差矩阵奇异（无法求逆，马氏距离失效）。

```
Σ_personal = λ·Σ_population + (1-λ)·Σ_sample

Σ_population = 与大五人格相似度 > 0.8 的群体协方差矩阵
λ 由 Ledoit-Wolf 解析解自动计算，无需手动设计衰减策略
```

新用户的初始空间 = 与其大五人格相似的群体大样本空间（提供稳定的骨架）。随着个人数据增多，Ledoit-Wolf 自动降低 λ，让个人数据逐步主导。

> 与旧方案（手动 α 衰减）的对比：
> - 旧方案：α = n/30 线性衰减，需要手动设定阈值
> - 新方案：λ 由 Ledoit-Wolf 自动计算，数据驱动，理论最优

### 空间成熟度的语义

空间体积（协方差行列式）本身是一个有意义的信号，反映用户的心理状态和生命周期：

| 空间特征 | 含义 | 对应 L5 人格模型 | 预测特点 |
|:--------|:----|:----------------|:--------|
| **体积小 + 密度高** | 行为固化、自律、成熟 | 责任心↑ 神经质↓ 开放性↓ | 预测精度高，但可能抗拒变化 |
| **体积大 + 多峰分布** | 探索期、多面手、不稳定 | 开放性↑ 神经质↑ 责任心↓ | 预测精度低，但适应性强 |
| **体积突然变化** | 生活变故 / 人格漂移信号 | — | 触发漂移检测 |

> 体积大且呈现多峰分布（GMM 混合高斯），代表该用户处于探索期、多面手或情绪不稳定（如青少年或面临重大生活变故）。这本身就是一个极具价值的"用户生命周期/心理状态"特征。

## 六、空间漂移检测

### GMM 分量漂移监测

在 GMM 框架下，漂移检测监测的是**行为模式（分量）的变化**而非单高斯均值：

```
每个分量 k 独立监测：

1. 分量均值漂移：μ_k 的马氏距离（相对于该分量的历史分布）
   - 短期窗口（最近 30 条）vs 长期窗口（最近 200 条）
   - 连续 3 个窗口超过 χ² 阈值 → 触发该分量漂移告警

2. 分量权重漂移：π_k 的变化率
   - 某分量权重突然下降 → 该行为模式正在消失
   - 某分量权重突然上升 → 该行为模式正在强化
   - 新分量出现 → 全新行为模式涌现
```

### EWMA 趋势监控

```
对每个分量的均值施加指数加权移动平均：
  - 多个分量趋势一致朝向同一语义方向 → 标记为人格整体变化
  - 单个分量趋势偏移但其他分量稳定 → 标记为模式内变化
```

### 漂移响应

```
- 不立即丢弃历史数据
- 提高近期数据权重（增大时间衰减因子 α）
- 分量消失：保留历史记录，降低权重至接近 0
- 新模式涌现：增加 K，初始化新分量
- 明确识别为人格变化后，存档旧 GMM，从近期窗口重建
```

## 七、与矛盾检测的关系

在 GMM 框架下，矛盾检测基于**模式加权的惊讶度**而非单高斯马氏距离：

```
新行为 → 向量映射 → 行为向量 x
    ↓
Phase 1（K=1）：单高斯马氏距离
  惊讶度 = Mahalanobis(x | μ_cond, Σ_cond)
    ↓
Phase 2+（K≥1）：GMM 加权惊讶度
  对每个模式 k 计算：
    d_k = Mahalanobis(x | μ_k, Σ_k)
  惊讶度 = Σ π_k · d_k（模式加权平均）
    ↓
惊讶度 × 分布置信度 → 矛盾信号强度
    ↓
距离小 = 在人格空间内 = 正常行为
距离大 = 超出人格空间 = 高惊讶度 → 触发矛盾检测
```

> GMM 加权惊讶度的优势：一个行为可能在模式 A 下是异常（高 d_A），但在模式 B 下是正常（低 d_B）。加权平均自然反映了"在这个用户的心理态下是否异常"。
