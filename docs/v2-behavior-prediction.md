## 一、核心思路

```
不是"Caroline 压力大时会做什么（4 个选项）"
而是"Caroline 的行为向量空间"

每个人的 L5 人格模型定义 TA 专属的行为向量空间：
  - 空间维度 = 行为特征维度（心理学支撑 + 数据驱动补充）
  - 空间范围 = TA 历史上所有行为的向量分布
  - 空间密度 = 某些区域行为密集（高概率），某些区域稀疏（低概率）
```

### 为什么向量空间优于固定类别

| 对比 | 固定类别方案 | 向量空间方案 |
|:----|:-----------|:-----------|
| **预测空间定义** | 需手动定类别，难覆盖所有可能 | **自然涌现**，空间边界由数据定义 |
| **新行为处理** | 不在列表 → 惊讶度=1.0，每次都报警 | 在空间边界内 → 正常，超出 → 报警 |
| **粒度** | 粗（4-5 个选项） | **连续**，可无限细化 |
| **跨人比较** | 类别不同无法比较 | 向量空间同构，可比较不同人的空间形状 |
| **演化追踪** | 需手动更新类别 | 空间自然漂移，协方差矩阵自动反映变化 |

## 二、行为向量维度定义

采用**核心心理学维度 + PCA 补充维度**的混合架构：

```
核心维度（11 维，心理学支撑）：
  大五人格映射    5 维  ← 与 L5 人格模型共享语义
  能量与动机      4 维  ← 行为驱动力
  情绪效价        2 维  ← 与情感维度衔接

补充维度（3~5 维，数据驱动）：
  PCA 从行为语料提取  ← 覆盖长尾语义，确保空间完备性

总维度：14~16 维
```

### 2.1 核心维度详解

#### 大五人格映射（5 维）

| 维度 | 含义 | 低分端 | 高分端 | 对应 L5 人格模型 |
|:----|:----|:------|:------|:----------------|
| **开放性** | 对新事物的接受度 | 保守、传统、偏好熟悉 | 好奇、创新、偏好探索 | 核心价值观/决策倾向 |
| **责任心** | 自我控制与目标导向 | 随性、拖延、不注重细节 | 自律、有条理、追求成就 | 决策倾向/当前人生阶段 |
| **外向性** | 社交能量来源 | 内向、独处恢复能量 | 外向、社交获得能量 | 关系模式/情绪调节模式 |
| **宜人性** | 合作与利他倾向 | 竞争、怀疑、自我优先 | 合作、信任、利他 | 关系模式/核心价值观 |
| **神经质** | 情绪稳定性 | 情绪稳定、抗压 | 情绪敏感、易焦虑 | 情绪调节模式 |

#### 能量与动机（4 维）

| 维度 | 含义 | 低分端 | 高分端 |
|:----|:----|:------|:------|
| **消耗性/恢复性** | 行为对能量的消耗程度 | 恢复能量（休息、放松） | 消耗能量（运动、工作） |
| **主动性/被动性** | 行为的发起方式 | 被动响应（等待、接受） | 主动发起（计划、行动） |
| **风险偏好** | 对不确定性的态度 | 规避风险（安全、稳妥） | 追求风险（冒险、尝试） |
| **延迟满足度** | 对即时 vs 长期回报的偏好 | 即时满足（享乐、冲动） | 延迟满足（规划、投资） |

#### 情绪效价（2 维）

| 维度 | 含义 | 低分端 | 高分端 |
|:----|:----|:------|:------|
| **愉悦度（Valence）** | 情感的正负方向 | 不愉快、负面 | 愉快、正面 |
| **唤醒度（Arousal）** | 情感的激活程度 | 平静、放松 | 激动、紧张 |

> 注：此处只取 VAD 中的 VA 两维，Dominance（支配度）保留在情感维度独立设计中。行为预测关注"会做什么"，VA 两维已足够描述行为的情感驱动。

### 2.2 PCA 补充维度

当核心 11 维无法充分表达某些长尾行为时（如"研究天体摄影"），从大规模行为语料中通过 PCA 提取 3~5 个潜在行为因子作为补充：

```
为什么用 PCA 而非 LLM 动态生成：
  - 确定性：PCA 是确定性的数学变换，每次结果一致
  - 正交性：PCA 天然产出正交维度，避免冗余
  - 数据驱动：从真实行为数据中涌现，而非 LLM 主观判断
  - 跨人可比：潜在因子对所有用户含义一致
  - 低成本：一次计算，无需持续 LLM 调用
```

## 三、向量映射方案

采用**知识蒸馏（Teacher-Student）架构**：

```
┌─────────────────────────────────────────────────┐
│              离线标注阶段（Teacher）               │
│                                                   │
│  历史行为库 → LLM + 心理学 Prompt（Few-shot）      │
│  [系统提示：你是一个行为心理学家，请评估该行为      │
│   在以下维度的得分...]                             │
│    ↓                                              │
│  伪标签数据集（行为描述 → 11 维向量）              │
│    ↓                                              │
│  embedding 相似度缓存（复用相同行为的标注结果）     │
└─────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────┐
│              模型训练阶段（Student）               │
│                                                   │
│  伪标签 → 训练多任务回归网络 / 微调小 Transformer  │
│  11 维作为 11 个相关任务，共享底层特征提取层        │
│    ↓                                              │
│  轻量级 Student 模型（在线推理 < 1ms）             │
└─────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────┐
│              在线推理阶段                          │
│                                                   │
│  新行为 → 查 embedding 缓存                       │
│    ↓ 命中          ↓ 未命中                       │
│  复用缓存向量      Student 模型推理                │
│                      ↓ Student 置信度低            │
│                    LLM Zero-shot 推理（兜底）       │
│                      ↓                            │
│                    写入缓存                        │
└─────────────────────────────────────────────────┘
```

### Teacher：离线标注

使用 LLM + 心理学 Prompt（Few-shot），将历史行为库映射到 11 维核心空间中：

```
系统提示：你是一个行为心理学家。请评估以下行为在 11 个维度上的得分（-1.0 ~ 1.0）。

维度定义：
  开放性：保守(-1) ↔ 好奇(+1)
  责任心：随性(-1) ↔ 自律(+1)
  外向性：内向(-1) ↔ 外向(+1)
  宜人性：竞争(-1) ↔ 合作(+1)
  神经质：稳定(-1) ↔ 敏感(+1)
  消耗性：恢复(-1) ↔ 消耗(+1)
  主动性：被动(-1) ↔ 主动(+1)
  风险偏好：规避(-1) ↔ 追求(+1)
  延迟满足：即时(-1) ↔ 延迟(+1)
  愉悦度：负面(-1) ↔ 正面(+1)
  唤醒度：平静(-1) ↔ 激动(+1)

Few-shot 示例：
  行为："参加即兴戏剧工作坊"
  输出：[开放性=+0.9, 责任心=+0.3, 外向性=+0.7, ...]

  行为："一个人在家看 Netflix"
  输出：[开放性=-0.3, 责任心=-0.2, 外向性=-0.8, ...]
```

### Student：多任务回归网络

用 LLM 生成的伪标签（Pseudo-labels）训练轻量级模型：

```
多任务回归网络结构：
  Input: 行为描述 embedding（768 维）
    ↓
  共享层：2 层 Transformer / 2 层 MLP
    ↓
  11 个独立回归头（每个维度一个）
    ↓
  输出：11 维向量

  损失函数：每个维度独立 MSE + 维度间相关性正则化
```

### 三阶段渐进实现

| 阶段 | 做法 | 触发条件 | 一致性 | 成本 |
|:----|:----|:--------|:------|:----|
| **冷启动** | Teacher 离线标注历史库 + embedding 缓存复用 | 0~200 条 | 中 | 高 |
| **成长期** | 训练 Student 多任务回归网络，LLM 仅做 Zero-shot 兜底 | ≥ 200 条 | 高 | 低 |
| **持续校准** | Student 增量更新 + Teacher 周期性重标注 | 每周 | 高 | 极低 |

### 冷启动缓存机制

```
行为描述 → embedding 向量 → 检索最相似缓存
    ↓ 相似度 > 0.92          ↓ 相似度 ≤ 0.92
复用缓存向量                LLM Zero-shot 推理 → 写入缓存
```

> 对于极其罕见的小众行为（Student 模型没见过），触发 LLM 进行 Zero-shot 推理，保证语义不丢失——小众行为可能比大众行为更具人格判别力。

## 四、条件概率预测

### 条件高斯分布 + 仿射变换

上下文（如"今天工作好累"、"刚和伴侣吵架"）不只是简单的过滤器，而是**改变空间形状的物理场**。

假设用户的基础人格空间为 𝒩(μ₀, Σ₀)，上下文向量为 C（由 LLM 或文本模型编码）：

#### 均值平移（倾向性偏移）

```
μ_cond = μ₀ + W·C
```

W 为可学习的权重矩阵。例如："工作好累"这个上下文向量，经过 W 映射后，会让"社交性"均值大幅向负方向平移，让"恢复性"均值向正方向平移。

#### 协方差形变（确定性/随机性偏移）

```
Σ_cond = Σ₀ ⊙ diag(f(C))
```

f(C) 输出每个维度的缩放因子，>1 放大方差（行为变得不可预测），<1 缩小方差（行为变得刻板）：

| 上下文类型 | f(C) 效果 | 含义 |
|:----------|:---------|:----|
| 模糊（"平平无奇的一天"） | ≈ [1, 1, 1, ...] | 接近人格先验，预测分散 |
| 明确（"工作好累"） | 社交性↓ 恢复性↑ 主动性↓ | 行为聚焦在某些区域 |
| 强烈（"情绪崩溃"） | 所有维度 > 1 | 方差放大，可能做反常行为 |

#### 采样与预测

```
预测不再是"找最近的点"，而是在偏移后的新空间 𝒩(μ_cond, Σ_cond) 中
进行蒙特卡洛采样 → 生成最可能的行为向量 → 映射回自然语言描述
```

### 与数据量分级的融合

| 数据量 | 均值处理 | 协方差处理 | 说明 |
|:-----|:--------|:----------|:----|
| 同一上下文 < 30 条 | μ_cond = μ₀ + α·W·C（α = n/30） | Σ_cond = Σ₀（保持先验） | 向先验收缩，协方差不变形 |
| 同一上下文 ≥ 30 条 | μ_cond = μ₀ + W·C | Σ_cond = Σ₀ ⊙ diag(f(C)) | 全量偏移+形变 |

### 完整流程

```
人格先验 𝒩(μ₀, Σ₀)
    ↓
上下文 C → 上下文向量（LLM 编码）
    ↓
均值平移：μ_cond = μ₀ + W·C
    ↓
协方差形变：Σ_cond = Σ₀ ⊙ diag(f(C))
    ↓
数据不足时 → 向先验收缩（α 衰减）
数据充足时 → 直接使用条件分布
    ↓
蒙特卡洛采样 → 行为向量 → 映射回自然语言
```

## 五、空间成熟度判断

### 收敛判断

采用**动态 PCA 监测为主 + 固定阈值兜底**的双重判断：

```
每新增 10 条行为数据，重新计算 PCA：

1. 前 3 主成分特征向量方向余弦相似度 > 0.95
2. 协方差矩阵行列式变化率 < 5%

同时满足 → 判定空间"已成熟/收敛"
否则 → 继续监测
```

固定阈值作为兜底参考：

| 级别 | 条件 | 能力 |
|:----|:----|:----|
| **MVP** | N > D（12 维→≥13 条） | 协方差可逆，能区分极端异常（马氏距离） |
| **基础可用** | N > D(D+1)/2（12 维→≥78 条） | 协方差稳定，可做有意义概率预测 |
| **成熟** | PCA 收敛判定通过 | 对细微上下文敏感，可检测人格漂移 |

> D(D+1)/2 是协方差矩阵自由参数数量，12 维至少需要 78 条独立行为才能可靠估计。

### 冷启动群体先验

在数据不足（空间未成熟）时，直接使用个人数据会导致协方差矩阵奇异（无法求逆，马氏距离失效）。

```
Σ_current = α · Σ_population + (1-α) · Σ_personal

Σ_population = 与大五人格相似度 > 0.8 的群体协方差矩阵
α 初始 = 1.0，每 10 条行为衰减 0.1，最小 0
```

新用户的初始空间 = 与其大五人格相似的群体大样本空间（提供稳定的骨架）+ 个人少量行为的微调。随着个人数据增多，α 逐渐衰减到 0。

### 空间成熟度的语义

空间体积（协方差行列式）本身是一个有意义的信号，反映用户的心理状态和生命周期：

| 空间特征 | 含义 | 对应 L5 人格模型 | 预测特点 |
|:--------|:----|:----------------|:--------|
| **体积小 + 密度高** | 行为固化、自律、成熟 | 责任心↑ 神经质↓ 开放性↓ | 预测精度高，但可能抗拒变化 |
| **体积大 + 多峰分布** | 探索期、多面手、不稳定 | 开放性↑ 神经质↑ 责任心↓ | 预测精度低，但适应性强 |
| **体积突然变化** | 生活变故 / 人格漂移信号 | — | 触发漂移检测 |

> 体积大且呈现多峰分布（GMM 混合高斯），代表该用户处于探索期、多面手或情绪不稳定（如青少年或面临重大生活变故）。这本身就是一个极具价值的"用户生命周期/心理状态"特征。

## 六、空间漂移检测

### 双窗口 CUSUM 检验

- 短期窗口（最近 30 条）vs 长期窗口（最近 200 条）
- 计算均值向量的马氏距离
- 连续 3 个窗口超过 χ² 阈值 → 触发人格漂移告警

### EWMA 趋势监控

- 对每个维度均值施加指数加权移动平均
- 多个维度趋势一致朝向同一语义方向 → 标记为人格变化

### 漂移响应

- 不立即丢弃历史数据
- 提高近期数据权重（增大时间衰减因子 α）
- 明确识别为人格变化后，存档旧模型，从近期窗口重建

## 七、与矛盾检测的关系

```
新行为 → 向量映射 → 马氏距离 → 惊讶度
    ↓
惊讶度 × 分布置信度 → 矛盾信号强度
    ↓
距离小 = 在人格空间内 = 正常行为
距离大 = 超出人格空间 = 高惊讶度 → 触发矛盾检测
```

## 八、整体实现路径

| Phase | 内容 | 数据要求 |
|:----|:----|:--------|
| **Phase 1（MVP）** | 固定 11 维核心维度 + LLM 直接输出向量 + 简单多元高斯 + 整体平移 | ≥ 30 条 |
| **Phase 2（增强）** | PCA 补充维度 + embedding 映射模型训练 + 贝叶斯收缩条件概率 | ≥ 200 条 |
| **Phase 3（演进）** | 漂移检测 + 群体先验库 + 主动学习 + 校准 | ≥ 500 条 |
