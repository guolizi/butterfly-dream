## 🧠 反思 Reflection（元认知）

**来源:** 原 README 功能列表（已移除，因尚未实现）

**核心思路:** 每次 LLM 自动提取后，系统自动分析全部已存储的事实，发现模式、矛盾、演化趋势，生成元事实写回库中。

**具体设计:**
- 触发：每 N 次提取后（如每 5 次）自动触发一次反思
- 输入：当前全部已存储事实（或按主题/实体分组）
- 输出：元事实 — 如「用户最近 3 次提到喜欢 VS Code」「用户在 X 和 Y 上观点矛盾」「用户对 Z 的偏好从 A 演变为 B」
- 存储：元事实写入同 DB，带特殊标记（如 category=meta）
- 检索：元事实参与正常检索，但可以按需过滤

**参考:**
- EPI-Memory v2 (NeurIPS 2025 workshop): 情景+过程性记忆统一建模，reflection 可视为其雏形

## 🌳 记忆树导航（Topic Tree）

**核心思路:** 将扁平事实库组织为层次化的主题树，支持按主题浏览和导航。

**参考:** 原 `docs/future-features.md`

---

## 🤝 Multi-Agent Shared KG

**来源:** NeurIPS 2024 ext. 2025

**核心思路:** 去中心化知识图谱同步，多 Hermes 实例共享记忆而不依赖中央服务器。

**适用场景:** 多 Agent 部署时需要，当前单 Agent 暂不需要。

---

## 🧪 Memory Benchmark（统一评测）

**来源:** arXiv 2025

**核心思路:** 标准化测试集，统一评测检索精度+遗忘曲线+跨 session 推理+记忆污染。

**说明:** 不是功能特性，而是验证工具——做改进时可用它检验效果。
