## 详细分析：最值得借鉴的评测集

### 1. LongMemEval — 与我们最相关

**论文**: "LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory"
**arxiv**: 2410.10813

**5 个认知维度**:
1. **信息提取 (Information Extraction)** — 从记忆中检索特定事实
2. **信息综合 (Information Synthesis)** — 综合多 session 信息回答问题
3. **时序推理 (Temporal Reasoning)** — 理解事件发生的时间
4. **一致性检查 (Consistency Checking)** — 检测用户信息中的矛盾
5. **溯因推理 (Abductive Reasoning)** — 从观察模式推断解释

**数据集**: 500+ 精心策划的问题，基于合成和真实对话

**我们已覆盖**: ✅ 信息提取, ✅ 时序推理, ✅ 一致性检查, ✅ 信息综合(跨会话检索)
**我们缺失**: ❌ 溯因推理（从观察推断解释，如「用户最近常提到疲劳+加班，推断可能工作压力大」）

---

### 2. LoCoMo — 多会话真实对话

**论文**: "LoCoMo: Long Conversation Memory"
**arxiv**: 2406.13756

**5 种推理类型**:
1. **事实知识回忆** — 回忆对话中提到的具体事实
2. **时序推理** — 推理事件发生的时间
3. **空间推理** — 推理位置和空间关系
4. **因果推理** — 理解因果关系
5. **对抗鲁棒性** — 抵抗误导信息

**数据集**: 50 个长期对话，300+ 轮/对话，8-9 session，人工生成问题

**我们已覆盖**: ✅ 事实回忆, ✅ 时序推理, ✅ 对抗鲁棒性(对抗相似)
**我们缺失**: ❌ 空间推理, ❌ 因果推理

---

### 3. LoTa-Bench — 任务导向评测

**论文**: "LoTa-Bench: Benchmarking Long-term Memory in LLM Agents"
**arxiv**: 2410.01378

**核心思路**: 不仅测记忆本身，还测记忆是否真正服务于任务完成

**4 个维度**:
1. **任务完成率** — Agent 是否成功完成任务
2. **记忆检索精度** — 从过去 session 检索相关信息的准确率
3. **记忆利用度** — 检索到的记忆是否被有效利用
4. **时序感知** — 理解信息何时被提及

**我们已覆盖**: ✅ 记忆检索精度(我们的核心指标)
**我们缺失**: ❌ 任务完成率（端到端从对话到任务结果）, ❌ 记忆利用度（记忆是否真的帮助了回答）

---

### 4. RULER — 上下文窗口极限测试

**论文**: "RULER: What's the Real Context Size of Your Language Model?"
**arxiv**: 2404.06654

**13 合成任务**:
1. Single/Multi/Multi-Key Needle-in-a-Haystack
2. Variable Tracking — 跟踪上下文中的变量变化
3. Common/Frequent Word Extraction — 提取常见词
4. QA over long contexts
5. Aggregation Tasks — 跨上下文聚合信息

**我们已覆盖**: ✅ 遗忘曲线(类似 NIAH)，✅ 变量跟踪(记忆编辑)
**我们缺失**: ❌ 聚合任务（从多处信息聚合回答）, ❌ 真实超长上下文测试(100K+)

---

### 5. StreamBench — 流式交互中的学习

**论文**: "StreamBench: Towards Benchmarking Continuous Improvement..."
**arxiv**: 2406.08250

**核心思路**: 评测 Agent 在流式交互中的连续改进能力

**我们已覆盖**: ❌ 完全没覆盖（这是全新维度）

## 值得借鉴的设计思路

### ✅ 我们已经做得好的
1. **端到端测试** (对话→提取→存储→检索) — LongMemEval/LoCoMo 也是这样
2. **多维度覆盖** — 我们有 46 检索场景 + 20 提取场景，覆盖面很广
3. **中英双语** — 多数英文评测集不支持中文
4. **遗忘曲线测试** — RULER/LongMemEval 也有类似设计
5. **事实合并/矛盾检测** — LongMemEval 的一致性检查

### ❌ 我们可以借鉴的新维度

1. **溯因推理** (LongMemEval) — 从观察推断解释
   - 例: 用户最近提到「失眠」「加班」「头痛」→ 推断「工作压力大」
   
2. **空间推理** (LoCoMo) — 推理位置关系
   - 例: 「用户住在东京但在大阪工作」→ 「用户通勤距离很远」

3. **因果推理** (LoCoMo) — 理解因果关系
   - 例: 「用户换了编辑器因为旧的太慢」→ 验证因果链

4. **记忆利用度** (LoTa-Bench) — 记忆是否真正帮助了回答
   - 不仅测「找到了没有」，还测「找到后有没有用上」

5. **信息聚合** (RULER) — 从多处信息综合回答
   - 例: 用户在 session 1 说喜欢咖啡，session 3 说戒了 → 「用户以前喜欢咖啡但现在戒了」

6. **任务完成率** (LoTa-Bench) — 端到端任务完成
   - 不仅测记忆系统，还测记忆系统对 Agent 整体表现的影响

7. **流式学习** (StreamBench) — Agent 在对话中持续学习
   - 测试记忆系统是否支持 Agent 随时间积累知识
